# Background
Leading up to this point, I never really programmed anything as low level as C in the form of a project. I had tons of experience (although old now) with python, and lots of recent experience in java, but hardly any in C. So
when I decided to do a snake algorithm project in C, I was a little worried that I would be biting off way more than I could chew. I was correct in some aspects, but also very wrong in others. I got through this project without many hitches, and it
really helped me get in the weeds of debugging (since I never took on a project close to being this complex before).

# Info / Progress
So far, the game is playable by a human and three simple bots, one that targets the apple directly, another that targets the apple while avoiding hitting itself, and one that can create a guaranteed win path on an even sized board. Progress has been made on trying to create a fourth bot that can make smarter moves, although it still has a long way to go.
